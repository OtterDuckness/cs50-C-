# CS50 C Projects 💻

This repository contains my solutions and practice work from Harvard's CS50 (Introduction to Computer Science), focused on programming in C.

It’s basically a collection of small programs that helped me go from “what is a variable?” to actually understanding how code works under the hood.

---

## 🚀 What This Repository Includes

- Problem set solutions (CS50-style exercises)
- Practice programs
- Experiments while learning C
- Console-based applications

Most of the programs are simple, but each one focuses on a specific concept.

---

## 🧠 What I Learned

Working through these exercises taught me:

### 🧩 Core Programming Concepts
- Variables and data types (`int`, `float`, `char`, etc.)
- Conditionals (`if`, `else`, `switch`)
- Loops (`for`, `while`)
- Functions and modular code

### 🔍 Memory & Low-Level Thinking
- How memory works in C
- Pointers and addresses
- Arrays and strings (and why strings are tricky)

### ⚙️ Problem Solving
- Breaking problems into smaller steps
- Writing logic before code
- Debugging (a lot of debugging)

### 📦 Libraries & Tools
- Using the CS50 library (`cs50.h`) for input handling
- Compiling programs with `gcc`
- Running programs in a terminal environment

---

## 🛠️ Technologies Used

- **Language:** C  
- **Compiler:** GCC  
- **Tools:** Terminal / Command Line  
- **Library:** CS50 Library (`cs50.h`)  

---

## 📚 About CS50

CS50 is an introductory computer science course by Harvard that teaches programming fundamentals using C, and later moves into other languages and topics.

This repo covers the early part — where things are harder, lower-level, and honestly more painful… but also where you learn the most.

# Proyectos de CS50 en C 💻

Este repositorio contiene mis soluciones y trabajos de práctica del curso CS50 de Harvard (Introducción a la Informática), centrado en programación en C.

Básicamente es una colección de pequeños programas que me ayudaron a pasar de “¿qué es una variable?” a entender realmente cómo funciona el código por dentro.

---

## 🚀 Qué incluye este repositorio

- Soluciones de problem sets (ejercicios estilo CS50)
- Programas de práctica
- Experimentos mientras aprendía C
- Aplicaciones de consola

La mayoría de los programas son simples, pero cada uno se centra en un concepto concreto.

---

## 🧠 Qué he aprendido

Trabajar en estos ejercicios me enseñó:

### 🧩 Conceptos básicos de programación
- Variables y tipos de datos (`int`, `float`, `char`, etc.)
- Condicionales (`if`, `else`, `switch`)
- Bucles (`for`, `while`)
- Funciones y código modular

### 🔍 Memoria y pensamiento a bajo nivel
- Cómo funciona la memoria en C
- Punteros y direcciones
- Arrays y cadenas de texto (y por qué las strings son complicadas)

### ⚙️ Resolución de problemas
- Dividir problemas en pasos más pequeños
- Pensar la lógica antes de programar
- Depuración (muchísima depuración)

### 📦 Librerías y herramientas
- Uso de la librería de CS50 (`cs50.h`) para manejar la entrada de datos
- Compilación de programas con `gcc`
- Ejecución de programas en terminal

---

## 🛠️ Tecnologías utilizadas

- **Lenguaje:** C  
- **Compilador:** GCC  
- **Herramientas:** Terminal / Línea de comandos  
- **Librería:** CS50 Library (`cs50.h`)  

---

## 📚 Sobre CS50

CS50 es un curso introductorio de informática de Harvard que enseña los fundamentos de la programación usando C, y más adelante introduce otros lenguajes y temas.

Este repositorio cubre la parte inicial — donde todo es más difícil, más cercano al hardware y, siendo sinceros, más frustrante… pero también donde más se aprende.
